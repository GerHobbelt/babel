# @gerhobbelt/babel-plugin-proposal-private-methods

> This plugin transforms private class methods

See our website [@gerhobbelt/babel-plugin-proposal-private-methods](https://babeljs.io/docs/en/next/babel-plugin-proposal-private-methods.html) for more information.

## Install

Using npm:

```sh
npm install --save-dev @gerhobbelt/babel-plugin-proposal-private-methods
```

or using yarn:

```sh
yarn add @gerhobbelt/babel-plugin-proposal-private-methods --dev
```
